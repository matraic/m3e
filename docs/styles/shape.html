Shape

Material Design 3 shape uses corner size and shape family to give surfaces their outlines. The rounded family curves corners; the cut family replaces the curve with a straight edge. M3E maps these families to CSS round and bevel, respectively.

Shape tokens

Corner size is independent of family. Material corner tokens such as --md-sys-shape-corner-extra-large provide radii; component properties such as --m3e-card-shape can override them. A zero radius leaves a square corner regardless of family.

Set --m3e-shape-family on an ancestor to change the default family for supporting components. It defaults to round. The core logical-corner properties --m3e-shape-family-start-start, --m3e-shape-family-start-end, --m3e-shape-family-end-start, and --m3e-shape-family-end-end can override individual corners. Logical corners follow writing direction and writing mode.

Supporting surfaces can also define their own family and logical-corner properties. Generally, each corner resolves its component corner override first, then the component family, the core corner override, and finally the core family. Some related surfaces have additional fallbacks; see each component's CSS properties.

Browser support Cut and other non-round corners require CSS corner-shape support. Browsers without it retain rounded corners. The examples also require an M3E build with shape-family support. See supported browsers. Shape-aware components

Shape-family properties are available on surfaces in Avatar, Badge, Bottom Sheet, Breadcrumb, Button, Callout, Card, Chips, Content Pane, Datepicker, Dialog, Drawer Container, Expansion Panel, FAB, FAB Menu, Icon Button, List, Menu, Navigation Bar, Navigation Menu, Search, Skeleton, Snackbar, Swipe Reveal, Tabs, Timepicker, TOC, Toolbar, Tooltip, and Tree. Options and option panels also support families, as does the core floating panel. Support applies to specific surfaces, not necessarily every element or part of a module.

Families also apply to interactive surfaces such as buttons. The button keeps its existing state-dependent corner sizes while using the selected family.

.cut-button {
  --m3e-button-shape-family: bevel;
}
 Other corner shapes

Family properties accept CSS corner-shape values beyond Material's rounded and cut families. For example, squircle creates a softer, superellipse-like corner. These are CSS extensions rather than additional Material shape families.

Squircle
A CSS corner shape
 
<m3e-card class="shape-card squircle-card">
  <!-- Content omitted for brevity -->
</m3e-card>
 
.shape-card {
  --m3e-card-shape: var(--md-sys-shape-corner-extra-large, 28px);
}
.squircle-card {
  --m3e-card-shape-family: squircle;
}
