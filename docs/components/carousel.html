Carousel

The m3e-carousel presents a scrollable collection of related content in responsive Material 3 layouts. Depending on the variant, it shows differently sized items that preview neighboring content, fixed-width items, or one edge-to-edge item at a time in a vertical fullscreen layout. Users navigate by dragging, swiping, or using the keyboard. Items can contain images, video, or custom content with optional title and subtitle overlays. 

import "@m3e/web/carousel";
 Usage

This section outlines usage examples and configuration guidance for the components in this module.

Anatomy

Use m3e-carousel to present a collection of m3e-carousel-item elements in its default slot. Each item accepts media or custom non-interactive content in its default slot, and optional title and subtitle slots for text overlays.

 Media

Place an img or video directly inside an item to fill its fixed content area with a centered object-fit: cover crop. As items expand or contract during scrolling, the carousel reveals or hides portions of the media rather than resizing it. 

<m3e-carousel-item label="View the coast">
  <img src="[YOUR IMAGE URL HERE]" alt="" loading="lazy" />
</m3e-carousel-item>

<m3e-carousel-item label="Play coastal tour">
  <video src="[YOUR VIDEO URL HERE]" poster="[YOUR IMAGE URL HERE]"
    muted playsinline preload="metadata"></video>
</m3e-carousel-item>

Use alt="" when an image is decorative and the item's title or label already describes its action. Provide meaningful alternative text when the image conveys information not covered by that text.

Carousels can contain more images than are initially visible. Use loading="lazy" on offscreen images so the browser can defer loading them until they are near the viewport. Keep initially visible or otherwise critical images eager to avoid delaying their display.

Variants

There are five carousel layout variants: multi-browse (default), uncontained, hero, hero-centered, and fullscreen. Use the variant attribute to change the layout.

Multi-browse

Set variant="multi-browse" to browse several related items at once. The carousel sizes items to fit the available space, showing large items alongside medium and small previews when they fit. Near the end of the collection, previews move ahead of the large items so the final item can come fully into view. The carousel snaps after a swipe, and a fast swipe can advance several items.

 Uncontained

Set variant="uncontained" for a horizontal layout with consistently sized items. It shows as many items as fit and clips neighboring items at the edges, hinting that more content is available. Unlike all other variants, it scrolls freely without snapping to an item when scrolling ends. Users can drag or use the mouse wheel to stop anywhere along the collection, including between items. A fast swipe carries the collection forward with inertia, gradually slowing to a stop. Title and subtitle overlays remain visible throughout scrolling, keeping each item's text readable rather than fading as it moves toward the edges.

 Centered hero

Set variant="hero-centered" to place large items between small previews, keeping the featured content visually centered. At the start of the collection, both previews appear after the large items to show the content that comes next. As users navigate through the collection, the previews shift around the large items. Near the end, both previews appear before them so the final items can come fully into view. If there are too few items to fill the centered arrangement, the collection aligns to the start instead. Like hero, the carousel snaps into position after a swipe and advances at most one item, even when users swipe quickly.

 Fullscreen

Set variant="fullscreen" to present one edge-to-edge item at a time in a vertically scrolling carousel. This layout gives each item the full viewing area, making it well suited to portrait images, videos, and other full-bleed content. Users move up and down through the collection by scrolling, swiping, or using the keyboard. After a swipe, the carousel snaps into position and advances at most one item, even when users swipe quickly. Title and subtitle overlays remain visible as items move, keeping their text available throughout navigation. Unlike the horizontal layouts, this variant ignores the --m3e-carousel-item-width preference and sizes each item to fill the carousel's height by default.

 Grid layout

Use m3e-carousel-grid as a vertically scrolling layout for a collection of m3e-carousel-item elements. Unlike the carousel's moving sequence, the grid presents items together in responsive rows and columns.

The grid can also serve as a Show all view. Display it in place of the carousel or on a dedicated page, rendering the same collection in both components. When switching between views, transfer selectedIndex to preserve the user's navigation position.

The grid adds columns as space permits. Set --m3e-carousel-grid-item-min-width (default 240px), --m3e-carousel-grid-item-gap (default 16px), or --m3e-carousel-grid-item-aspect-ratio (default 4 / 3) to tune its layout.

This following example displays 16 destinations in a compact, multirow grid. Its reduced minimum item width fits more destinations per row, while its maximum width keeps the layout from stretching too wide. 

<m3e-carousel-grid class="carousel-grid-demo" aria-label="Featured destinations">

 Sizing and spacing

Use CSS custom properties on m3e-carousel to customize item widths, gaps, and gutters to suit your content and available space. Set the carousel's height directly with CSS or through its height custom properties. Together, these settings control how much of the collection is visible and the space around each item.

Item widths

Set --m3e-carousel-item-width to control how wide items should be. Its effect depends on the layout variant:

  • multi-browse, hero, and hero-centered use it as a preferred width for large items. The carousel adjusts the actual width to fit large items and previews into the available space. A smaller preference allows more large items to fit.
  • uncontained uses it as a fixed item width, capped by the available space.
  • fullscreen ignores it because each item fills the carousel's width.

Without an explicit width, multi-browse and uncontained use 280px. hero and hero-centered target one large item with room for their previews. Widths accept CSS lengths and percentages, including calc(), and can be changed with media or container queries. 

.carousel {
  --m3e-carousel-item-width: 320px;
}

For finer control of responsive layouts, use --m3e-carousel-small-item-min-width and --m3e-carousel-small-item-max-width to set the small preview range, which defaults to 40px through 56px. --m3e-carousel-large-item-max-width limits large items and defaults to 100% of the available space. Very narrow containers can omit previews when there is not enough room for them.

Carousel height

Set the carousel's height to control its overall viewing area. All variants default to 205px. Horizontal items fill that height minus the top and bottom gutters, while fullscreen items fill the entire height. 

.carousel {
  height: 256px;
}

Alternatively, use --m3e-carousel-height to change the default height through an inheritable CSS custom property. --m3e-carousel-min-height sets the minimum height and defaults to 0.

Item gaps and gutters

Use --m3e-carousel-item-gap to set the space between horizontal items, which defaults to 8px. For fullscreen, use --m3e-carousel-fullscreen-item-gap instead. Its default is 16px.

Horizontal layouts also reserve space around the collection for shadows and focus rings. The --m3e-carousel-inline-gutter property defaults to 16px at each horizontal edge, and --m3e-carousel-block-gutter defaults to 8px above and below the items. These gutters are inside the carousel's dimensions, so increasing them reduces the space available for items. 

.carousel {
  --m3e-carousel-item-gap: 16px;
  --m3e-carousel-inline-gutter: 24px;
  --m3e-carousel-block-gutter: 12px;
}

Increase the gutters when custom shadows or focus rings need more room. Feedback is still clipped at the carousel's outer boundary. fullscreen ignores both gutter properties and stays edge-to-edge.

Titles and subtitles

Use slot="title" and slot="subtitle" to display text over an item's media or content. Both slots are optional. The text sits near the bottom of the item, inset 16px from the sides and bottom, and aligns to the left in left-to-right layouts or to the right in right-to-left layouts. 

<m3e-carousel-item>
  <img src="[YOUR IMAGE URL HERE]" alt="" />
  <span slot="title">Coast</span>
  <span slot="subtitle">Follow the ocean breeze</span>
</m3e-carousel-item>

In multi-browse, hero, and hero-centered, both texts are visible on large items. As an item contracts during scrolling, the title gradually fades out as it approaches medium size, followed by the subtitle as it approaches small preview size. The text fades without changing its font size. In uncontained and fullscreen, both texts remain visible throughout scrolling.

Titles use Title Large typography and subtitles use Body Medium, both with white text by default. Customize their appearance with CSS custom properties on m3e-carousel to style the collection, or on an individual m3e-carousel-item to style only that item. The following example uses smaller text for a more compact presentation. 

.carousel {
  --m3e-carousel-item-title-font-size: 20px;
  --m3e-carousel-item-subtitle-font-size: 12px;
}

Set --m3e-carousel-item-text-color to change both text colors together. Use --m3e-carousel-item-title-text-color or --m3e-carousel-item-subtitle-text-color when the title and subtitle need different colors.

Text scrim

A text scrim is an optional gradient behind the title and subtitle that helps separate the text from the item's media or content. It is strongest near the bottom and fades to transparent above the text, leaving the rest of the item unobscured.

Check text contrast A scrim can improve text contrast, but it does not guarantee readability over every image or video. Check the text against your actual content and adjust the scrim opacity or text colors as needed.

Enable it with the --m3e-carousel-item-scrim-opacity CSS custom property on m3e-carousel or an individual m3e-carousel-item. Values range from 0 to 1, with larger values producing a stronger scrim. The default is 0, which turns it off. The photo examples on this page use 0.65. 

.carousel {
  --m3e-carousel-item-scrim-opacity: 0.65;
}

The scrim uses the theme's Material Scrim color by default. Set --m3e-carousel-item-scrim-color to use a different color. Its visibility follows the title and subtitle as they fade during scrolling, and it disappears when both texts have faded out. Items without either text slot do not show a scrim.

Selected item and programmatic navigation

Use the selected-index attribute or selectedIndex JavaScript property to read or set the carousel's current navigation position. The index starts at 0 and follows the order of the items collection, which excludes hidden items. The carousel also updates this position as users navigate through the collection.

Call movePrevious() or moveNext() to navigate one item at a time, or moveTo(index) to go to a specific item. Navigation stops at the first and last items rather than wrapping around. These methods reveal the requested item without activating its action or moving keyboard focus.

Listen for the bubbling change event to respond when user navigation or a navigation method changes the current item. Its detail.index contains the new position and detail.item contains the corresponding m3e-carousel-item element. Setting selected-index or selectedIndex directly updates the position without emitting this event. 

const carousel = document.querySelector("m3e-carousel");

carousel.addEventListener("change", event => {
  console.log(event.detail.index, event.detail.item);
});

carousel.moveTo(2);

The carousel does not render navigation buttons. If your application provides controls, place them above or below the carousel rather than inside its items or beside it. A Show all action can offer an alternative way to browse the full collection, as described in Grid layout.

m3e-carousel-grid supports the same navigation properties, methods, and change event. Each component maintains its own position. When switching between a carousel and a grid, copy selectedIndex if the destination view should resume at the same item.

Item actions and links

Each m3e-carousel-item provides one primary action that covers the entire item. By default, it behaves as a button. Listen for its click event to perform an application action, such as opening a detail view or starting video playback.

Set href to make the item a link instead. Use target to choose where the destination opens, rel to describe the link relationship, or download to request a download. These attributes work like their native anchor counterparts. 

<m3e-carousel-item href="/destinations/coast">Coast</m3e-carousel-item>
<m3e-carousel-item id="tour">Play coastal tour</m3e-carousel-item>

document.querySelector("#tour").addEventListener("click", () => {
  // Perform the application's action.
});

Clicking or tapping a preview also activates its button action or follows its link. The carousel makes that item current and scrolls to reveal it fully after release. Dragging or swiping navigates the collection without activating an item, so users can browse without triggering its action.

Disabling and hiding

Set disabled on an item to disable its action and exclude it from keyboard navigation. Use hidden on an item to remove it from the layout; adding, removing, and hiding items updates the arrangement. 

<m3e-carousel aria-label="Destinations">
  <m3e-carousel-item>Coast</m3e-carousel-item>
  <m3e-carousel-item disabled>Forest unavailable</m3e-carousel-item>
  <m3e-carousel-item hidden>Mountains</m3e-carousel-item>
</m3e-carousel>
 Shape and interaction feedback

Horizontal items have rounded corners and elevate on hover. Use CSS custom properties on m3e-carousel or individual m3e-carousel-item elements to customize this feedback. Set --m3e-carousel-item-shape to change the resting corner radius, which defaults to 28px, and --m3e-carousel-item-hover-elevation to change the hover shadow, which defaults to elevation level 1. fullscreen items are square and do not elevate on hover by default.

Items also have a 1px outline that does not change their content dimensions. Customize its width and color with --m3e-carousel-item-outline-width and --m3e-carousel-item-outline-color. Set the width to 0 to remove it. This outline is separate from the keyboard focus ring, which appears outside horizontal items and inside fullscreen items.

Pressing an item reduces its corner radius toward 16px. Set --m3e-carousel-item-shape-pressed-morph to use a different pressed radius. The pressed shape never increases a smaller resting radius, and starting a drag cancels the pressed appearance. 

.carousel {
  --m3e-carousel-item-shape: 24px;
  --m3e-carousel-item-shape-pressed-morph: 12px;
}

See the API documentation for additional CSS custom properties that control state-specific outlines, state layers, and ripples.

Accessibility

Both m3e-carousel and m3e-carousel-grid use role="grid" and follow the ARIA layout grid pattern, with row and gridcell roles organizing a button or link action in each cell. The collection has one Tab stop, with arrow keys moving focus between its actions. Horizontal carousels form one row, fullscreen forms one column, and m3e-carousel-grid arranges items in responsive rows and columns. Navigating changes the current position without marking items as selected for assistive technology.

Give each m3e-carousel and m3e-carousel-grid an accessible name using aria-label or aria-labelledby so users can identify the collection. Slotted content supplies each item's action name, including title and subtitle text that has visually faded out. Set the item's label attribute when it needs a clearer action name, especially for image-only content.

Follow the alternative-text guidance in Media when naming images. Each item is a single action, so do not place links, buttons, native video controls, or other interactive elements inside its content.

Each collection has one Tab stop. Tab enters at the remembered enabled item action. Pressing Tab again moves out of the collection, and Shift+Tab moves out in the opposite direction. Use navigation keys to move focus between items without activating them.

For m3e-carousel, use the following navigation keys:

  • Left Arrow and Right Arrow move between horizontal items.
  • Up Arrow and Down Arrow move between fullscreen items.
  • PageUp and PageDown move backward and forward by approximately one viewport, or one item in fullscreen.
  • Home and End focus the first and last enabled items.

For m3e-carousel-grid, use the following navigation keys:

  • Left Arrow and Right Arrow move between enabled items within the current row.
  • Up Arrow and Down Arrow move between rows, keeping the column when possible.
  • PageUp and PageDown move by approximately one viewport of rows.
  • Home and End focus the first and last enabled items in the current row.
  • Hold Ctrl or Meta with Home or End to focus the first or last enabled item in the entire grid.

In both components, Enter activates buttons and links, while Space activates buttons. Navigation skips disabled actions and does not wrap. Moving focus reveals the item so users can see the action they are about to activate.
