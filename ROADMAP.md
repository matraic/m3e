# 📍 M3E Roadmap

This roadmap summarizes work in progress, future direction, and major release milestones. Planned work is directional and may change; milestones are not tied to specific release dates.

## 🚧 In Progress

### ✨ Components

- Carousel
- Form-field composite inputs (text, date, number, combobox, etc.)

## 🔮 Planned

### ✨ Components

- Standalone numeric and masked inputs
- Scroll view (overscroll stretch effect, auto-hide scrollbars)

## 🏛️ Major Milestones

- **2.12.0**
  Added `@m3e/mcp`.

- **2.11.0**
  Added `@m3e/web/swipe-reveal` and app-bar scroll behaviors.

- **2.10.0**
  Added `@m3e/web/callout`, switch improvements, and loading-indicator pull-to-refresh support.

- **2.9.0**
  Updated `@m3e/web/theme` to use the 2025 spec, correcting color variant support, and updated components to support standard/expressive motion.

- **2.8.0**
  Added `@m3e/web/gestures`, form-field manual error state, and settable select value.

- **2.7.0**
  Added `@m3e/web/date-input` and text scaling support.

- **2.6.0**
  Added `@m3e/web/timepicker`.

- **2.5.0**
  Added `@m3e/web/breadcrumb` and `@m3e/web/content-pane`.

- **2.4.0**
  Added `@m3e/web/tree`.

- **2.3.0**
  Added `@m3e/web/split-pane`, `@m3e/web/skeleton`, and `@m3e/icons`.

- **2.2.0**
  Added `@m3e/web/calendar`, `@m3e/web/datepicker`, `@m3e/web/search`, and the `change` event to `@m3e/web/autocomplete`.

- **2.0.0 — Major release**  
  Unified architecture under `@m3e/web`, introduced `@m3e/react` (React bindings), consolidated components, and deprecated legacy per‑component packages.

- **1.3.0**
  Added `@m3e/bottom-sheet`.

- **1.2.0**
  Expressive updates to `@m3e/menu` and introduction of the rich tooltip in `@m3e/tooltip`.

- **1.1.7**
  Added `@m3e/avatar`, expressive updates to `@m3e/list`, and new selection/action patterns.

- **1.1.3**
  Added the wavy appearance variant to `@m3e/progress-indicator`.

- **1.1.0**
  Added `@m3e/paginator`, bundle size reductions, and RTL layout fixes.

- **1.0.6**
  Added `@m3e/autocomplete`, `@m3e/select`, and `@m3e/option`.

- **1.0.3**
  Added `@m3e/stepper`.

- **1.0.0**
  First full, stable version of the M3E component library.
